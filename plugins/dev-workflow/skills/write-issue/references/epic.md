# Epic template

An Epic is a group of stories. Create it as the tracker's epic item, which the tracker file
names.

## Fields

| Field | Value |
| --- | --- |
| Name | A title, by the rules in "Titles" |
| Summary | One line, where the tracker has a summary field. The tracker file gives its limit. |
| Description | The template below |
| Team | From the profile |
| Lead | The answer to "who leads the epic" |
| Status | From the profile |

## Description

```markdown
As a <role>, I want <goal> so that <benefit>.

## Out of scope

- <A related change that this epic does not make.>
```

The story sentence follows the rules in the [story template](story.md).

The description holds no list of stories, because the tracker lists the issues of the
epic. It holds no acceptance criteria, because no PR closes an epic.

## The stories

Draft each story from the story template, and put it in the epic. Show the epic and its
stories in one draft.
