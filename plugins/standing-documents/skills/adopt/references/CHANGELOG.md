# Changelog of the standing-documents guide

Each entry names one version of `adopt-standing-documents.md`. It says what changed, and what
a project that adopted an earlier version does about it. The newest entry comes first. A
version below 1.0 is alpha.

## 0.1.0

**What changed:** This is the first numbered version. The guide now has a version line under
its title. The map holds a fifth thing, the version line, and "Adoption" says how to upgrade.

**Action:** A project that adopted the guide before 0.1.0 adds the version line to its map.
Example: "This project follows the standing-documents guide 0.1.0, at
`https://github.com/toppa/claude-plugins/tree/main/plugins/standing-documents/skills/adopt/references`."
